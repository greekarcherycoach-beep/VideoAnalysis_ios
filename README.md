# Archery Lab – Ανάλυση Τεχνικής (PWA)

Video analysis τεχνικής τοξοβολίας: καταγραφή, αργή κίνηση καρέ προς καρέ και σημειώσεις πάνω στο βίντεο.

## Δημοσίευση στο GitHub Pages
1. Δημιούργησε νέο repository στο GitHub (π.χ. archery-lab).
2. Ανέβασε **όλα** τα αρχεία αυτού του φακέλου στη ρίζα του repo (μαζί με το κρυφό .nojekyll).
3. Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save.
4. Μετά από ~1 λεπτό η εφαρμογή είναι στο https://USERNAME.github.io/REPO/

## Εγκατάσταση στο κινητό / υπολογιστή
- Android (Chrome): μενού ⋮ → Εγκατάσταση εφαρμογής.
- iPhone (Safari): Κοινοποίηση → Προσθήκη στην οθόνη Αφετηρίας.
- Desktop (Chrome/Edge): εικονίδιο εγκατάστασης στη γραμμή διευθύνσεων.

## Ενημερώσεις
Όταν αλλάζεις αρχεία, άλλαξε το όνομα cache στο sw.js (archery-lab-v6 → v7 κ.λπ.).
